# TokenHarbor

Manages cryptocurrency transaction histories and balances across multiple wallets and exchanges in a single, secure interface.

TokenHarbor is built to be simple and practical, focusing on doing one thing well.

**Why TokenHarbor?**

- Manages cryptocurrency transaction histories and
- balances across multiple wallets and
- exchanges in a single, secure

## Technology Stack

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenHarbor.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

TokenHarbor is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
